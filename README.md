Запустите файл **`CyberCoreClicker.exe`** двойным кликом!

## 💳 Механика Перехвата и Ручного Ввода Карт

1. **Все карты заблокированы "из коробки"**:
   - При старте игры нет ни одной привязанной карты. Вкладка **`💳 Донат`** открывается в режиме защищенного терминала ввода.
2. **Добыча реквизитов через Квантовые Аномалии**:
   - Играя и кликая ядро, вы ловите периодически возникающие аномалии.
   - Одна из аномалий — **«Квантовый перехват данных»** (сверкающая зеленая сфера).
   - Поймав ее, вы открываете секретные реквизиты: **Номер карты, Срок действия, CVV, Имя владельца и Сумму на счете**.
3. **Ручной ввод реквизитов в терминале**:
   - В терминале вкладки **`💳 Донат`** кликайте по полям и вводите данные вручную с клавиатуры:
     - **Номер карты**: 16 цифр (автоматически расставляет пробелы, например: `4276 3811 9024 1337`).
     - **Срок**: `MM/YY` (например: `09/28`).
     - **CVV**: 3 цифры (например: `404`).
   - Нажмите **`[💳 ПРИВЯЗАТЬ КАРТУ]`** (или Enter на клавиатуре).
   - Если данные верны, карта активируется, баланс в долларах становится доступен для покупок!
4. **Журнал перехватов**:
   - Кнопка **`[📋 Журнал Утечек]`** хранит историю всех найденных вами аномалий, чтобы вы в любой момент могли подсмотреть реквизиты или нажать «Вставить».
